# Gabriele Corso — Portfolio
Sito statico senza processo di compilazione. Aprire index.html oppure servire la cartella con un server HTTP.

## Contenuti
- Sei progetti con schede raggiungibili tramite #progetto/identificatore.
- PDF originale H-AI nella cartella assets.
- Modulo facoltativo che prepara un messaggio nell'app email o WhatsApp, senza archiviazione lato server.
- biglietto.html genera QR SVG/PNG nel browser e una vCard.
- Movimento disattivabile e preferenza di sistema rispettata.

## Configurazione
config.js contiene solo i recapiti destinati alla pubblicazione e l'URL pubblico.
Non inserire chiavi o credenziali.

## Pubblicazione
GitHub Pages: branch main, cartella radice. Nessuna dipendenza da installare.
La libreria QR è inclusa in vendor/qrcode.js (MIT, Kazuhiko Arase).
Il saggio e i testi rimangono attribuiti a Gabriele Corso.
